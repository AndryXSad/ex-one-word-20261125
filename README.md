A program that writes one word describing an ex to `/output/entry.txt`.
The word is **Unskippable** — an ex as an ad you cannot skip: the ordeal you
were forced to sit through. It won a local pairwise tournament of 20
candidate words, judged on the bounty judge's own criteria (verdict on an ex
first, then comic punch, surprise, craft, recognition), beating "Placeholder"
in the final and "Refunded" in the semi-final.

## Run it

```sh
python3 main.py
```

The program writes `entry.txt` (11 bytes, exactly `Unskippable`) into
`$MAKEFUN_OUTPUT_DIR`, or `/output` when that variable is unset. Standard
library only; deterministic — two runs produce byte-identical output.
